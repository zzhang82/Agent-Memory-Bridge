# v0.26.0 - MCP 2026-07-28 Stdio Compatibility

Agent Memory Bridge 0.26.0 is a bounded compatibility release for MCP
2026-07-28 over local stdio. It uses `mcp==2.0.0` and keeps the AMB product
surface unchanged.

## What changed

- Modern clients can use `server/discover` over real spawned stdio.
- Legacy initialize-based clients still work over real spawned stdio.
- Modern results include `resultType: "complete"`.
- `tools/list` returns the same 13 public tools in deterministic order with
  `ttlMs: 0` and `cacheScope: "private"`.
- Meaningful per-request `clientInfo` can populate caller-declared
  `source_client` when no explicit `source_client` is supplied. Precedence is
  explicit input > meaningful MCP context > environment default; generic `mcp`
  is ignored.
- Schema remains v7. No database migration and no tool additions.

## Validation

- Isolated Windows CPython 3.11 suite: `622 tests collected`; all runnable
  tests passed; `3 platform-conditioned skips`; no failures
- Dual-era stdio proof: modern `server/discover` and legacy `initialize` both
  exercised through real spawned stdio
- Public MCP tool count: 13
- Modern result shape: `resultType: "complete"` on modern results
- Tool-list shape: deterministic ordering, `ttlMs: 0`, and
  `cacheScope: "private"`

## Boundaries

This release does not add HTTP hosting, MCP Tasks, MCP Apps, OAuth/ACL,
new public tools, a database migration, Episode Ledger, active reranking, or
policy automation.

Caller-declared provenance is still not authenticated identity. Retrieval
feedback remains shadow-only and does not change memory records, indexes,
recall ordering, or ranking.
