# v0.26.1 - Protocol Conformance and Operator Proof

Agent Memory Bridge 0.26.1 tightens the evidence around the MCP 2026-07-28
stdio adapter shipped in 0.26.0. It does not add product features, public MCP
tools, or durable schema changes.

## What changed

- `server/discover` now has an explicit `ttlMs: 300000`,
  `cacheScope: "public"` contract.
- `tools/list` keeps `ttlMs: 0`, `cacheScope: "private"`, and emits the 13
  public tools from one canonical order.
- Raw JSON-RPC fixtures cover modern discover/list/call, legacy
  initialize/initialized/list/call, unsupported versions, missing modern
  envelopes, malformed `clientInfo`, and legacy field isolation.
- A real `mcp==1.28.1` client runs in a separate environment against the MCP
  2.0 AMB server and completes initialize, list, store, and recall.
- The official `@modelcontextprotocol/client@2.0.0` client completes modern
  discover, list, store, and recall.
- `doctor --include-stdio` and `verify` report modern and legacy paths
  independently and use disposable databases rather than the live store.
- Bounded protocol observability records client name/version, protocol
  version, hashed request ID, capabilities digest, and trace ID without
  logging raw capabilities, baggage, or request identifiers.
- CI has dedicated Python MCP SDK 1.x, Python MCP SDK 2.x/raw-wire, and
  TypeScript MCP SDK 2.0 compatibility jobs. The MCP boundary modules are
  included in mypy and branch-coverage gates.

## Reliability proof

The local acceptance run completed:

- 641 tests collected for the full repository suite
- 20 concurrent mixed modern/legacy stdio processes writing to one SQLite
  database: 20 writes retained, no lock error
- 100 alternating modern/legacy connect-disconnect cycles: no protocol error
- no direct child process remained after the connection loop
- no temporary proof artifact reported after the connection loop
- negotiation-only raw-wire cases left the schema-v7 database dump unchanged

These are project interoperability proofs, not official MCP conformance-suite
results. The proof also does not authenticate client metadata or certify Codex,
Claude Code, OpenCode, or another host product.

## Unchanged boundaries

- schema remains v7; there is no migration
- the public MCP surface remains exactly 13 tools
- retrieval feedback remains append-only, shadow-only, and ordering-neutral
- no HTTP hosting, OAuth/ACL, Tasks, Apps, Episode Ledger, reranking, or new
  memory taxonomy is included

Publication is gated on a visible complete GitHub Actions green run for the
release tag commit. This document distinguishes that release proof from the
local and cross-SDK evidence above.
