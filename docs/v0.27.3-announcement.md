## Credit and consolidation closure

- Utility projections join only current effective feedback and current outcome
  heads, with relation consistency checked atomically. `helpful`,
  `misleading`, `outdated`, `not_applicable`, and `not_used` remain distinct;
  `not_applicable` and `not_used` are never collapsed into one counter.
- Supporting and contradicting run counts require the matching relation,
  effective feedback head, terminal outcome, and governed authority. The
  `memory_utility_shadow` projection keeps `shadow_score = 0.0`.
- Workspace consolidation uses bounded keyset pagination rather than a
  single 500-run cutoff. A stable `candidate_subject_id` identifies the claim
  subject; a separate `evidence_revision_id` changes when supporting,
  contradicting, neutral, or procedure evidence changes.
- Procedure structure conflicts are contested and never select a procedure
  variant. Deterministic structured opposition is deduplicated and scoped to
  the named candidate subject.
- Independence is reported in two lanes: declared independence uses declared
  thread/session/evidence relationships; verified independence additionally
  requires strong governed receipts and distinct trusted evidence sources.

## Authority and privacy boundary

Run identity/configuration and work-item identity are immutable except for the
server-managed generation transition. Run events, outcomes, artifacts, and
memory links remain append-only authority. Server-minted artifact references
carry validated digest/MIME/URI metadata only; inline bodies, receipt-shaped
values, hidden reasoning, path-like private payloads, and secret-like values are
rejected before durable persistence. Provenance remains declared, not
authenticated.

`consolidate-runs --shadow` remains read-only. `--stage` can create only hidden
`needs_review` learning candidates for human review. Utility and consolidation
do not change ranking, policy, prompts, ordinary memory, or perform automatic
writeback.

Run rows remain durable episode authority; downstream learning/consolidation effects are shadow-only.
