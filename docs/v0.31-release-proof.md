# v0.31 Clean-Room Release Proof

This explicit release gate tests a built distribution in a temporary virtual
environment. It does not use an editable install or import AMB from the checkout
`src/` tree.

Run the wheel proof with the version expected from installed package metadata:

```bash
python tools/evidence/v031_release_smoke.py --expected-version 0.31.1
```

For bounded machine-readable evidence, add `--json`. To exercise the source
distribution instead of the wheel, add `--artifact sdist`.

The proof builds a wheel and sdist, runs `twine check`, installs the selected
artifact into a temporary environment, and verifies:

- a committed temporary repository produces real, commit-bound repository WHAT;
- public MCP `store` writes an explicit project decision and a distinct fresh MCP
  launch recalls that durable WHY together with repository WHAT;
- the CLI-only Knowledge Explorer preserves `derived_projection`,
  `derived_repository`, and `governed_durable_memory` authority distinctions;
- existing relation and supersession governance controls the active projection;
- `inspect` reports the supported repository provenance and read-only boundary;
- the same active WHY reaches Task Memory `decision_hits`, Inspect selection, and
  the Context Compiler `[Project Decision]` label;
- public MCP `revise` leaves the predecessor inactive and the successor active
  across Recall, Task Memory, Inspect, Context Compiler, and Explore;
- the public MCP surface remains 17 tools, contains no `explore` tool, and retains
  the canonical tool-schema digest;
- Explorer does not mutate durable database content or repository snapshot
  content, repository facts do not become durable memory, and no learning,
  feedback, promotion, model API, or remote product-service operation is part of
  the proof.

All fixture, bridge, database, log, configuration, repository-snapshot, and
virtual-environment state is temporary. Normal dependency installation may use
the package index; the product smoke stages themselves use only local Git,
SQLite, CLI, and MCP stdio paths.

Run this proof against the current source/package version. For the v0.31.1
release-prep head, that version is `0.31.1`.
