# Agent Memory Bridge v0.31.1 — Project WHY Alignment

v0.31.0 made project knowledge inspectable.

v0.31.1 closes the consistency gap: when you explicitly teach AMB a project
decision or constraint, the same active governed WHY now flows through the
context path that powers Inspect and model context.

Code tells AMB WHAT the project is.
Conversations teach AMB WHY it is that way.

This document is the canonical release-notes artifact for the `0.31.1`
source/package line. It does not claim that a GitHub Release or PyPI package
already exists.

## Project WHY Alignment

- `record_type: decision` and `record_type: constraint` are first-class
  governed task-memory lanes (`decision_hits` / `constraint_hits`).
- Inspect and the Context Compiler consume that same governed selection.
- Selected WHY is labeled `[Project Decision]` or `[Project Constraint]`.
- The project-WHY candidate scan is bounded, then filtered.
- Revision, supersession, validity, lineage, and structured-metadata
  governance remain in force.
- Relation-expanded invalid structured WHY does not bypass governance.

## Project Learning Promotion Polish

Primary onboarding is:

connect → bootstrap WHAT → teach WHY → fresh session → Inspect + Explore

- `first-run` remains secondary guided durable-memory help.
- `doctor` and `verify` are optional health and troubleshooting checks.
- Human-facing docs keep the WHAT / WHY mental model; agent docs may specify
  the public MCP `store` contract.
- Stale, dirty, and missing-binding recovery copy is actionable.

## Stable boundaries

- Durable schema remains v12.
- Public MCP surface remains exactly 17 tools.
- Knowledge Explorer remains CLI-only; there is no MCP tool #18.
- Public tool-schema digest remains:
  `24c5c52321d61b4b6f647c0d74e2d8304ca68716c403e08a274e9badfd8dc9f8`
- Repository WHAT remains derived and rebuildable.
- There is no `pip install agent-memory-bridge==0.31.1` route.

## Explicit non-claims

This release does not add:

- automatic learning
- automatic durable repository writeback
- automatic ranking adaptation
- a new MCP tool
- a schema migration
- project init or namespace suggestion
- a UI, dashboard, or graph database

It also does not claim that AMB understands an entire codebase, that agents
always follow memory, or that productivity improved.
