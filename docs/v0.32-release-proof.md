# v0.32 Clean-Room Release Proof

This explicit release gate builds and installs a distribution in a temporary
virtual environment outside the checkout source tree.

Run the wheel proof with:

```bash
python tools/evidence/v032_release_smoke.py --expected-version 0.32.0
```

Use `--artifact sdist` for the source-distribution path and `--json` for bounded
machine-readable evidence.

The proof verifies the installed package version and origin, schema v12, the
17-tool public MCP surface and unchanged schema digest, then exercises the v0.32
Project Learning journey in a disposable committed Git repository:

- first Project Init detects the repository, proves the deterministic suggested
  and chosen namespace, initializes derived repository WHAT, renders Human-first
  Explore, and creates no durable-memory rows anywhere in the fresh database and
  no learning-candidate or retrieval-feedback rows;
- public MCP stdio stores one explicit decision and one explicit constraint with
  reasons;
- fresh Human-first Explore shows CODE / WHAT and CONVERSATION / WHY without raw
  authority enums, memory IDs, or graph syntax;
- Recall, Task Memory, Inspect, Context Compiler, and Explore agree on the active
  governed project decision;
- repeat Project Init says repository WHAT was refreshed and existing project WHY
  is unchanged, while preserving exact WHY IDs and content;
- dry-run, default-NO decline, and dirty-worktree paths remain zero-write or
  fail-closed;
- installed source retains post-confirm revalidation and persists the fresh
  snapshot rather than the pre-confirm plan;
- technical Markdown retains graph/audit relationships and repeated
  `knowledge-explorer-v1` JSON is byte-identical.

All bridge homes, databases, logs, snapshots, fixture repositories, builds, and
virtual environments are temporary. The proof makes no automatic-learning,
ranking-adaptation, productivity, hosted-service, or external-adoption claim.
