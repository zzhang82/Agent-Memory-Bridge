# Agent Memory Bridge v0.33.1 — Operational Coherence

Agent Memory Bridge v0.33.1 is a patch on the stable v0.33 operational line. It makes the existing product easier for coding agents to use by adding one canonical semantic memory-use policy, thin Codex/OpenCode/generic host renderers, and a frozen invocation evaluation. It does not add a new durable authority, expand the public MCP surface, or enable automatic learning.

```bash
pip install agent-memory-bridge==0.33.1
```

This document is the canonical release-notes artifact for the `0.33.1` source/package line. Live publication state is external: use GitHub Releases for the source release and PyPI for package availability. Publication continues through PyPI Trusted Publishing with GitHub OIDC after the matching GitHub Release is published.

## What changed

- One canonical semantic policy now decides when a host should consult configured AMB memory. Host adapters change placement, not meaning.
- `memory-policy` renders a reviewed Markdown or JSON block for Codex, OpenCode, or a generic instruction surface. The command is export-first and refuses to overwrite an existing file.
- Frozen semantic-invocation eval v1 scores observable recall decisions. A statement that an agent remembered is not invocation evidence. The checked-in report currently has no actual host evidence, so missing host trials are `NOT RUN / UNOBSERVED`, not PASS.
- The active documentation surface is smaller: `INSTALL_FOR_AGENTS.md` is the detailed install authority, `llms.txt` is a map, and historical harness/startup/routing notes are no longer current product docs.

Installing the package does not automatically connect every coding agent. Each coding client must be configured separately, and clients that should share project memory must point at the same persistent `AGENT_MEMORY_BRIDGE_HOME`.

## Compatibility and authority boundaries

- Durable schema remains v12.
- Public MCP surface remains exactly 17 tools.
- The public tool-schema digest remains `24c5c52321d61b4b6f647c0d74e2d8304ca68716c403e08a274e9badfd8dc9f8`.
- There is no MCP tool #18.
- There is no automatic learning.
- The policy does not inspect hidden reasoning, persist transcripts, or write durable memory.
