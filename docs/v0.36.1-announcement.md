# Agent Memory Bridge v0.36.1 — Structure Over Prose & Memory Hygiene

Agent Memory Bridge v0.36.1 establishes anti-pollution memory hygiene for coding agents and documents the core principle: **Encode lessons in structure over prose**. The schema remains v12 and the public MCP surface remains exactly 17 tools. There is no automatic learning and no MCP tool #18.

## What is in v0.36.1

This maintenance release codifies operational memory hygiene developed across multi-agent production loops:

1. **Structure Over Prose Principle**:
   If an agent makes the same mechanical mistake twice, harden the repository environment (ESLint, Biome, Ruff, strict type narrowing, pre-commit checks)—do not write more prompt text into memory. Mechanical rules in memory cost tokens on every recall and fail to prevent repeat errors deterministically.
2. **The 3-Question Ingestion Filter**:
   Before storing durable memory (`kind="memory"`), evaluate:
   - *Can a linter catch it?* Configure the linter; do not store in AMB.
   - *Can static types or runtime assertions enforce it?* Harden types/schemas; do not store in AMB.
   - *Is it an irreversible architectural decision, domain boundary, or external SDK gotcha?* Store in AMB.
3. **Dedicated Memory Hygiene Guide**:
   Published in [`docs/MEMORY-HYGIENE.md`](MEMORY-HYGIENE.md) with concrete Decision, Gotcha, and Learn record templates.
4. **Authority Contract & Ecosystem Alignment**:
   Cleaned up historical legacy framework references in the authority contract. The official companion skills repository ([`Agent-Memory-Skills`](https://github.com/zzhang82/Agent-Memory-Skills)) was updated in tandem to enforce these redlines in the everyday `amb` and `amb-connect` skills.
