# Agent Memory Bridge v0.37.0 — Documentation Stabilization & Adoption Simplification

Agent Memory Bridge v0.37.0 delivers documentation stabilization and adoption simplification across coding agent hosts. The schema remains v12 and the public MCP surface remains exactly 17 tools. There is no automatic learning and no MCP tool #18.

## What is in v0.37.0

This release completes the two near-term roadmap priorities identified in the post-v0.36.1 roadmap:

1. **Repository & Documentation Stabilization**:
   - Re-anchors `docs/PRODUCTION-STATUS.md` as the single canonical source of truth for checked-in current-source facts.
   - Standardizes the 4-tier data lifecycle architecture in `docs/ARCHITECTURE.md`:
     1. *Durable Authority* (SQLite records, Dynamic State head, Episode runs).
     2. *Derived Views* (rebuildable repository snapshots, FTS5 indexes, Knowledge Explorer projections).
     3. *Transient Data* (in-process compiled prompt context, manifest tokens).
     4. *Historical Evidence* (prior release announcements, benchmark snapshots).
   - Updates `docs/ROADMAP.md` to reflect near-term goals delivered and focus advancing to medium-term activation.

2. **Adoption & Installation Simplification**:
   - Enriches `docs/INTEGRATIONS.md` with standardized, copy-pasteable host configuration recipes for:
     - **Cursor**: `.cursor/mcp.json`
     - **Claude Code**: `.mcp.json` at project root or `~/.claude.json`
     - **OpenCode**: `~/.config/opencode/opencode.json`
     - **Zero-Install Runner**: `uvx agent-memory-bridge serve`
   - Documents standardized cross-platform onboarding diagnostics (`doctor` and `verify`) with verified exit codes: `0` (healthy), `1` (check failed), `2` (CLI option mismatch).

## Client boundary

Installing the package does not automatically connect every coding agent. Clients that should share one store still point at the same persistent `AGENT_MEMORY_BRIDGE_HOME`.

## PyPI Distribution and release provenance

The version-pinned distribution command is:

```sh
pip install agent-memory-bridge==0.37.0
```

GitHub Releases is the source publication authority; consult it and PyPI for live availability. PyPI Trusted Publishing uses GitHub OIDC. After the release PR merges, tag `v0.37.0` must resolve to that release merge SHA. The package and GHCR workflows verify tag, package, and source identity, then check the installed wheel, sdist, or container before publication. A tag alone is not publication evidence.

This release requires no schema migration and adds no public tool. Upgrading an existing deployment is a separate step for the operator.
