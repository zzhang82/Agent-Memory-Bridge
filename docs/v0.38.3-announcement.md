# Agent Memory Bridge v0.38.3 — Recall Lifecycle, Recheck Confirmation, and Record-Type Scope

Agent Memory Bridge v0.38.3 closes three follow-up issues without changing the public MCP surface. Default recall now applies the existing supersession and contradiction lifecycle, repository recheck can record a confirmation, and an HTTP gateway principal can optionally limit record types. The schema remains v12 and the public MCP surface remains exactly 17 tools. There is no automatic learning and no MCP tool #18.

## What changed since v0.38.2

- **Default recall:** A memory that is the target of a current `supersedes` or `contradicts` relation is suppressed from ordinary recall. `eligibility="historical"` still returns it. Ranking weights are unchanged, and task-memory assembly keeps its own lifecycle reporting.
- **Recheck confirmation:** A repository dependency with uncommitted changes reports `unknown` rather than `current`. An annotation tag `confirmed_against:<commit>` records that a decision was checked against a later commit without revising its content. Without that tag, the stored dependency commit remains the baseline.
- **Gateway record scope:** `allowed_record_types` is optional on a gateway principal. When set, `store`, `annotate`, and `revise` refuse a record type outside the list. When omitted, role and namespace behavior is unchanged. Local stdio and the static single-token profile do not apply it.
- **Scope:** No schema migration, public tool argument, or tool-schema digest change is included. The published `v0.38.2` tag and artifacts remain historical.

## Compatibility and limitations

Installing the package does not automatically connect every coding agent. Clients that should share one store still point at the same persistent `AGENT_MEMORY_BRIDGE_HOME`.

- The public tool-schema SHA-256 remains `24c5c52321d61b4b6f647c0d74e2d8304ca68716c403e08a274e9badfd8dc9f8`.
- There are exactly 17 tools in the public MCP interface, and the schema remains v12.
- No schema migration is required for existing v12 data.
- Age is not a recall ranking input, and `decay_if_unseen` remains unread.
- A confirmation tag does not cover dependencies outside AMB records and Git, and it does not name a remote checkout.
- The gateway does not add human approval, cross-principal ownership checks, OAuth or token issuance, TLS termination, or human/model identity.
- This release does not authorize upgrading an existing production deployment. That remains an independent operator decision.

## PyPI Distribution and release provenance

After this release is published, install the version-pinned package with:

```sh
pip install agent-memory-bridge==0.38.3
```

GitHub Releases remains the release source of truth, and actual PyPI and GHCR availability must be checked separately. Publishing a GitHub Release for the `v0.38.3` tag triggers the existing wheel/sdist verification workflow, PyPI Trusted Publishing through GitHub OIDC, and the container workflow that validates and publishes `ghcr.io/zzhang82/agent-memory-bridge:0.38.3`. A tag alone is not evidence that either artifact was published.
