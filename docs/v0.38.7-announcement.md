# Agent Memory Bridge v0.38.7 — Operator Memory CLI

Agent Memory Bridge v0.38.7 adds the `memory` CLI subcommand group (`list`, `show`, `forget`, and `revise`), allowing operators to inspect, retrieve, tombstone-delete, and revise durable records directly from the terminal without launching an MCP client. The schema remains v12 and the public MCP surface remains exactly 17 tools. There is no automatic learning and no MCP tool #18.

## What changed since v0.38.6

- **Operator memory CLI (#104):** Adds `python -m agent_mem_bridge memory {list,show,forget,revise}` for terminal-level inspection and governance:
  - `memory list`: Lists stored memories in the current bound repository namespace (falling back to `project:demo` if unbound), with support for `--all` (across all namespaces), `--kind {memory,signal}`, `--query <text>`, `--limit <int>`, and `--json`.
  - `memory show <id>`: Displays full record metadata, tags, validity, recheck status, relations, and content. If a record was forgotten, surfaces its tombstone audit metadata.
  - `memory forget <id>`: Forgets and tombstones a memory row in one auditable transaction. Prompts for confirmation when interactive (skippable with `--yes` / `-y`), reports already-forgotten records, and supports `--reason` and `--json`.
  - `memory revise <id> --content <text>`: Atomically supersedes an existing record with replacement content, preserving supersession lineage and audit invariants. Rejects revising forgotten records or minting reserved policy tags. Supports `--title`, `--tag`, `--reason`, `--actor`, and `--json`.
- **Scope:** No schema migration, public tool argument, or tool-schema digest change is included. The published `v0.38.6` tag and artifacts remain historical.

## Compatibility and limitations

Installing the package does not automatically connect every coding agent. Clients that should share one store still point at the same persistent `AGENT_MEMORY_BRIDGE_HOME`.

- The public tool-schema SHA-256 remains `24c5c52321d61b4b6f647c0d74e2d8304ca68716c403e08a274e9badfd8dc9f8`.
- There are exactly 17 tools in the public MCP interface, and the schema remains v12.
- No schema migration is required for existing v12 data.
- This release does not authorize upgrading an existing production deployment. That remains an independent operator decision.

## PyPI Distribution and release provenance

After this release is published, install the version-pinned package with:

```sh
pip install agent-memory-bridge==0.38.7
```

GitHub Releases remains the release source of truth, and actual PyPI and GHCR availability must be checked separately. Publishing a GitHub Release for the `v0.38.7` tag triggers the existing wheel/sdist verification workflow, PyPI Trusted Publishing through GitHub OIDC, and the container workflow that validates and publishes `ghcr.io/zzhang82/agent-memory-bridge:0.38.7`. A tag alone is not evidence that either artifact was published.
