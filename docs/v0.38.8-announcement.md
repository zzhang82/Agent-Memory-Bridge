# Agent Memory Bridge v0.38.8 — Live Repo Claim Drift, Remote Operator Memory CLI, and Hero Walkthrough

Agent Memory Bridge v0.38.8 adds recall-time live repository claim drift detection (surfacing stored claims vs live repo state with revise suggestions), extends the `memory` CLI subcommand group (`list`, `show`, `forget`, and `revise`) with `--url` and `--token-file` so operators can inspect and manage remote HTTP authorities directly from the terminal without launching an MCP client, and adds a silent 17-second hero loop walkthrough to the README. The schema remains v12 and the public MCP surface remains exactly 17 tools. There is no automatic learning and no MCP tool #18.

## What changed since v0.38.7

- **Live repo claim drift (#93):** When a recalled record references a commit or repo path that drifted from the live checkout, recall now surfaces:
  - `recheck_status: needs_recheck` and `recheck_reasons: [depends_on_repo:changed:<path>]`
  - `repo_divergence`: structured comparison including the `stored_claim`, `live_content_preview`, recorded vs current commits, git diff summary, and an actionable revise suggestion (`offer_revise`).
  - Terminal display via `memory show <id>` formats a clean `Live Repo Drift` block highlighting the drift and suggested revision.
- **Remote support for Operator Memory CLI:** Extends `python -m agent_mem_bridge memory {list,show,forget,revise}` with `--url` and `--token-file` to connect to remote Streamable HTTP authorities (such as Synology NAS or Docker deployments) directly from the terminal.
- **README hero loop walkthrough (#101, #105):** Adds a silent 17-second hero loop GIF and MP4 directly below the header banner, demonstrating an end-to-end local store and fresh-process recall walkthrough.
- **Scope:** No schema migration, public tool argument, or tool-schema digest change is included. The published `v0.38.7` tag and artifacts remain historical.

## Compatibility and limitations

Installing the package does not automatically connect every coding agent. Clients that should share one store still point at the same persistent `AGENT_MEMORY_BRIDGE_HOME` or remote HTTP endpoint.

- The public tool-schema SHA-256 remains `24c5c52321d61b4b6f647c0d74e2d8304ca68716c403e08a274e9badfd8dc9f8`.
- There are exactly 17 tools in the public MCP interface, and the schema remains v12.
- No schema migration is required for existing v12 data.
- This release does not authorize upgrading an existing production deployment. That remains an independent operator decision.

## PyPI Distribution and release provenance

```sh
pip install agent-memory-bridge==0.38.8
```

GitHub Releases remains the release source of truth, and actual PyPI and GHCR availability must be checked separately.
